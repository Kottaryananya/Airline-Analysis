# ✈️ Indian Airlines Performance Analysis Dashboard

## Overview

The Indian Airlines Performance Analysis Dashboard is an interactive Power BI project designed to analyse and compare major Indian airlines based on passenger traffic, profitability, customer ratings, flight operations, fuel efficiency, and environmental impact.

The dashboard enables users to explore airline performance through dynamic filters and visualisations, helping identify trends, operational strengths, and business opportunities across India's aviation industry.

## Key Metrics

The dashboard tracks:

- Total Passengers
- Passenger Capacity
- Customer Ratings
- Estimated Profit
- Fuel Efficiency
- Average Flight Duration
- CO₂ Emissions per Passenger

---

## Dashboard Features

### Airline Comparison

Compare major Indian airlines including:

- Air India
- IndiGo
- Akasa Air
- SpiceJet
- Star Air

### Interactive Filters

Users can filter data by:

- Airline
- Route
- Destination City

### Visualisations

- Monthly Passenger Trend Analysis
- Passenger Distribution by Airline
- Airline Ratings Comparison
- Profit Contribution Analysis
- KPI Summary Cards
